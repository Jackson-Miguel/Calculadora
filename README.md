# Calculadora

Projeto de uma calculadora web desenvolvida para realizar operações matemáticas básicas por meio de uma interface intuitiva.

## Sobre o projeto

A aplicação permite que o usuário realize cálculos matemáticos diretamente pelo navegador, utilizando botões interativos para inserir números e operadores.

## Funcionalidades

- Adição.
- Subtração.
- Multiplicação.
- Divisão.
- Operações com números decimais.
- Interface interativa.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

Projeto desenvolvido para praticar lógica de programação, manipulação do DOM, eventos JavaScript e estilização de interfaces web.
